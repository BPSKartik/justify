      Model Context Protocol

      Let your AI assistant check its own work.

      The assistant that writes the code can call Justify before it hands the code over. One URL, no account, no key:

      Private code, and proof

      The hosted audit reads public repositories and never runs anything. To audit private code, and to prove each removal by running your own tests on a temporary copy, run Justify locally:

      pip install "justify-code[mcp] @ git+https://github.com/BPSKartik/justify"
      justify scan . --prove "python -m pytest -q"

      As a local MCP server: command justify-mcp, with JUSTIFY_TEST_COMMAND (the only command it will run) and JUSTIFY_ALLOWED_ROOTS (the only folders it may read).

      Seven stages. The model never deletes.

      1. IngestEvery file read once and fingerprinted.
      2. Static factsSyntax trees, not text search: who uses what, across the whole repository.
      3. CandidatesAnything a graph can misjudge — frameworks, dynamic lookups, re-exports — waits for judgement.
      4. JustifyA model is asked why the unit exists, and must cite a file and line that is then checked.
      5. ChallengeA second call tries to prove the code is needed. If it can, the code stays.
      6. ProofRemoved in a temporary copy, then your tests run. A file the tests never load is “not provable”.
      7. ReportOne report with a reason on every line, and a ledger of every run. A person approves.

      This site runs stages 1–3 plus authorship. Stages 4–6 run on your machine, with your model and your tests.
