What Justify keeps, and who can read it

Plainly, in one page. Last changed 3 October 2026.

The short version

To audit code, the service has to read it while the audit runs — a few seconds. After that it keeps nothing it does not need, and nothing private that it can read. Your code is deleted. A private result is sealed with a key that never leaves your browser or your AI app.

Code you upload, or share with an AI app

  • It is unpacked into a temporary folder, audited, and that folder is deleted the moment the audit ends — finished or failed.
  • It is never sent to a model, never logged, never kept.
  • A zip is unpacked as if it were hostile: no paths outside itself, no links, no git settings that could run anything.

Private results are sealed

  • Before uploading, your browser makes a random 256-bit key and keeps it. The server holds the key in memory only while your audit runs, encrypts the result with AES-256-GCM, writes the ciphertext, and forgets the key.
  • When you open the audit, your browser downloads the ciphertext and decrypts it itself. The server never sees the key again — so neither Justify nor anyone with access to its storage can read the result.
  • Code shared through an AI app is sealed the same way; the app is given the key with the result.
  • To open a sealed audit on another device, use “Save the key” on the result. If the key is lost, the result cannot be recovered — by you or by us.

Audits of public repositories

They are about public code, so their results are public: anyone with the link can open them, and they appear under “Recently audited”. They are cached by commit so the same commit is never scanned twice.

Your account

  • A display name. With GitHub, also your username and picture — both public on GitHub already.
  • No email address, no password, and no key to your GitHub or Microsoft account: the provider's token is used once to read your name and then dropped.
  • Your history: which audits you ran, with their numbers (counts, ratios, languages) — never code or file names.
  • Sessions, personal tokens and AI-app tokens are stored only as SHA-256 fingerprints.

Your network address

Never stored. Without an account, the free daily allowance is counted under a keyed hash of your address; the key lives only in the server's memory and is replaced every day, so the counts cannot be turned back into addresses.

Where it lives

Microsoft Azure, Central India. The database and results are mirrored to a private Blob Storage container that the service reaches with its own managed identity; the storage account refuses keys, and Azure encrypts it at rest. Microsoft sign-in also uses that identity — there is no client secret.

Deleting it

Remove any audit from your history on the dashboard; deleting a private audit erases its sealed result. Delete my account, at the bottom of the dashboard, erases your profile, history, tokens, connected apps and every private audit at once. Justify is open source: read exactly what it does.
